# Changelog

All notable changes to this project preview will be documented here.

## 2026-11-08 (lanjutan)
- Video demo tanpa suara di README, 90 detik, menunjukkan alur pemakaian dengan kursor
- Endpoint AI bisa diarahkan ke gateway kompatibel OpenAI lewat `OPENROUTER_BASE_URL` (dipakai untuk demo lokal)
- Pendaftaran akun dibuka untuk umum, langsung masuk setelah daftar
- Validasi username, password, dan nama admin yang dipakai ulang
- Pembatas laju untuk daftar, masuk, unggah PDF, pembuatan soal, dan simpan sesi
- Dukungan Redis (Upstash) untuk batas lintas instance di produksi
- Pemeriksaan tanda tangan berkas PDF dan batas panjang teks kiriman
- Palet biru sesuai versi asli, tema gelap sebagai bawaan

## 2026-11-08
- Upgrade ke Next.js 16.4.5, React 19.3.1, Tailwind CSS 4.3.5, Zustand 5.1.0, dan TypeScript 5.9.3
- Migrasi middleware ke proxy, API request async, dan ESLint flat config
- Tampilan dirombak: palet kertas dan tinta, tema terang dan gelap dengan tombol di header
- Halaman kuis: navigasi nomor soal dan indikator jawaban
- Panel admin: konfirmasi hapus di tempat, status memuat dan galat
- Berkas logo ganda dihapus, tangkapan layar preview diperbarui
